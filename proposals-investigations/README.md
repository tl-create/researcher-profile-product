# Proposals & Investigations

Pre-initiative work: proposals, spikes, prototypes, and exploratory analyses that have not
(yet) graduated into an initiative under `initiatives/`.

Conventions:
- One folder per proposal/investigation, named `lowercase-with-hyphens`.
- Each folder has a README stating: question being investigated, status, and outcome
  (promoted to initiative / parked / rejected), with Jira links where they exist.
- When a proposal graduates, move its distilled content to `initiatives/` or `prds/`
  and leave the folder here with a pointer, for the paper trail.
